# かがみがみ — 写真を切って並べる万華鏡

写真を鏡に映したように 4 枚並べ、細い短冊に切って端から交互に並べ直す。短冊の数を変えるだけで、万華鏡のような模様が次々に変わる。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/kagamigami/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

**写真はこの端末の中だけで加工し、どこにも送りません。**

1. 写真を 1 枚えらぶ（「見本で試す」でも試せる）。PC ではドロップや貼り付け（⌘V / Ctrl+V）でも開ける。
2. 写真を鏡に映したように上下左右 4 枚に並べ、細い短冊に切って、左端・右端・左から 2 本目…と端から交互に並べ直す。横にも同じように切って並べる。
3. 「短冊の数」を動かすと模様が変わる（スライダーか「−」「＋」、PC は ← →）。できあがりを押しているあいだは元の写真が見える。
4. 鏡（4 枚・2 枚・なし）、並べはじめ（左上から・右下から）、切れ目（なし・あり）も選べる。
5. 「画像を保存」で JPEG に書き出す。スマホは共有シート（写真アプリに保存・そのまま送る）、PC はダウンロード。
   保存した画像には、撮影場所などの写真の情報は残らない（画面の中で描き直すため）。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 並べる順番・境目が整数・並べ直し（画素で）・大きさの上限・設定のテスト（フレームワークなし）
```

| ファイル | 中身 |
|---|---|
| `strips.js` | 画面に触らない中身。大きさの決まり、並べる順番、境目、タイル・切って並べる描き方、設定の読み込み |
| `main.js` | 画面・操作・読み込み・保存 |
| `sound.js` | 効果音（Web Audio で作る。音声ファイルなし） |
| `sample.js` | 「見本で試す」の画像（アプリの中で描く） |
| `test.mjs` | `strips.js` のテスト |

- 写真は `<input type="file">`・ドロップ・貼り付けからだけ受け取り、`URL.createObjectURL` → `<img>` → canvas で扱う。通信（`fetch` など）・解析・外部の資源は使わない。`index.html` の CSP（`connect-src 'none'` など）でも止めてある。
- 長辺 2000px の「保存用の元」と 600px の「画面用の元」を作る。鏡 4 枚でも保存は 4000 × 4000 以下（iPhone の canvas の上限 16,777,216 画素に収まる）。
- 保存するのは `localStorage` の `kagamigami.settings` だけ（`{ v: 1, cols, tile, start, gaps, seenHelp, sound }`）。写真・できあがりは保存しない。
